# Идея проекта

Telegram-бот, который по номеру телефона говорит, какому оператору и региону этот номер выделен в российской системе и плане нумерации.

Пользователь присылает номер в виде `7` и десяти цифр. Бот отвечает названием оператора и регионом. Если номера нет в реестре — сообщает, что номер не найден. Команда `/start` коротко объясняет формат.

Источник данных — открытые выгрузки реестра нумерации с портала открытых данных Минцифры (`opendata.digital.gov.ru`): файлы ABC-3xx, ABC-4xx, ABC-8xx и DEF-9xx. В выгрузке номер задан не поштучно, а диапазоном: код ABC/DEF, начало и конец, ёмкость, оператор, регион, территория ГАР и ИНН. Бот не определяет конкретного абонента и не показывает, кто владеет SIM-картой. Он показывает, кому из операторов и в какой регион этот номер выделен по плану нумерации.

Публичный бот: https://t.me/ProverkaNomeraTelefonaBot
