# Исходные данные: CSV реестра

[← Оглавление](project-docs.md)

## Источник

Открытые выгрузки реестра российской системы и плана нумерации с портала Минцифры:

- `https://opendata.digital.gov.ru/downloads/ABC-3xx.csv`
- `https://opendata.digital.gov.ru/downloads/ABC-4xx.csv`
- `https://opendata.digital.gov.ru/downloads/ABC-8xx.csv`
- `https://opendata.digital.gov.ru/downloads/DEF-9xx.csv`

`getcsv.sh` скачивает четыре файла в `inCSV/archive/YYYYMMDD/` (дата — текущая или первый аргумент скрипта) и копирует их в `inCSV/`. Дата каталога потом становится датой снимка при импорте. Загрузка идёт с `--no-check-certificate`.

## Формат файла

Кодировка UTF-8; BOM у заголовка есть не всегда (файлы читаются через `utf-8-sig`). Разделитель `;`, первая строка — заголовок. Кавычки в названии оператора не являются синтаксисом CSV и остаются частью текста.

| Индекс | Колонка CSV | Смысл |
|---|---|---|
| 0 | АВС/ DEF | код ABC или DEF, 3 цифры |
| 1 | От | начало 7-значного хвоста диапазона |
| 2 | До | конец хвоста, включительно |
| 3 | Емкость | размер диапазона; всегда равен `До − От + 1` |
| 4 | Оператор | наименование оператора; написание меняется от снимка к снимку |
| 5 | Регион | регион; несколько значений через `\|`; с выгрузки 2026‑10‑04 у части строк стоит `-` |
| 6 | Территория ГАР | территория по ГАР, тоже может содержать `\|`, в ABC-8xx — запятые |
| 7 | ИНН | ИНН оператора; одна строка в реестре с пустым ИНН |

Пример строки:

```
900;0000000;0061999;62000;ООО "Т2 МОБАЙЛ";Краснодарский край;Краснодарский край;7743895280
```

Полный номер собирается как `7` + код + хвост с ведущими нулями до 7 цифр.

## Свойства данных

Проверены на снимках 2024–2026 годов:

- внутри одного кода диапазоны не пересекаются — на этом построен поиск;
- ёмкость всегда равна размеру диапазона;
- один ИНН встречается с разными написаниями имени (регистр, сокращения), одно имя — с разными ИНН; ключ оператора — ИНН;
- «Регион» и «Территория ГАР» — составные строки, в ABC-8xx бывают значения вида «Российская Федерация, кроме …», которые на список не раскладываются.

## Чтение и валидация (`checkph/csv_reader.py`)

`read_snapshot(dir)` читает все `*.csv` каталога через `csv.reader` и возвращает список `RangeRow(code, from_number, to_number, operator_name, region_raw, gar_raw, inn)`. Пустые строки пропускаются, пустой ИНН становится `None`.

Снимок отклоняется с `SnapshotError`, если:

- в строке не 8 полей;
- код не из трёх цифр, границы не семизначные, начало больше конца;
- пустое имя оператора;
- ИНН не из 10 или 12 цифр;
- диапазоны одного кода пересекаются.

Несовпадение ёмкости с размером диапазона — только предупреждение в лог.
