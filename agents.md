# CheckPhNumber bot

Telegram-бот, который по номеру телефона отвечает, какому оператору и региону номер выделен по открытому реестру российской системы и плана нумерации Минцифры. Реестр хранится в SQLite диапазонами с историей версий по снимкам CSV; поиск — индексный, по диапазону; к номеру можно привязывать наблюдения внешних источников (владелец, спам). Код — пакет `checkph/` (схема, импорт, синхронизация с порталом, поиск, обогащение, бот) на Python 3.12 и aiogram 3, запуск из корня через `.venv`. Снимки архивируются zip в `inCSV/archive/YYYYMMDD.zip`. Сбор базы (`python -m checkph.sync` / `importer --backfill`) и работа бота (`python main.py`) — отдельные процессы.
